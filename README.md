# 🔐 Graphical Password Authentication

A **Graphical Password Authentication System** developed using **C#** as an academic project. The application explores an alternative to traditional text-based passwords by using graphical interactions for user authentication.

## 📌 Overview

Traditional password-based authentication can be vulnerable to attacks such as password guessing, brute-force attacks, and credential reuse. This project demonstrates a graphical authentication approach where users interact with graphical elements as part of the authentication process.

The system allows users to register and authenticate using a graphical password mechanism, providing a more interactive alternative to conventional text-based passwords.

## ✨ Features

- User registration and login
- Graphical password-based authentication
- Password verification
- User-friendly interface
- Authentication workflow implemented in C#

## 🛠️ Technologies Used

- **Language:** C#
- **Platform:** .NET
- **Development Environment:** Visual Studio

## 🔄 How It Works

1. The user creates an account.
2. During registration, the user sets a graphical password.
3. The graphical password information is used for authentication.
4. During login, the user reproduces the correct graphical password.
5. The system verifies the input and grants or denies access.
